# Versionsstaffelung

## Version 1
- Stabiler Player: MP3, Play, Pause, Stop, Fade Out
- Tempo, Pitch, Lautstärke, Basis-BPM, heutiges Tempo
- Pattern + Singing-Logik (7-Segment-Anzeige)
- Loop-In, Loop-Out, Feintuning, Testhören
- Songliste mit Suche, Songdaten, Import-Workflow
- Clubs und Specials als Kontexte (Lokationen)
- Abspielhistorie
- Playlist-Laufzeitlogik + Playlist-Builder (Filter, Sortierung, Empfehlung)
- Fade-Out (konfigurierbare Dauer)
- Auto-Advance bei Song-Ende, Stop und Fade-Out
- Fenstersteuerung über Player, Layout-Speichern/Wiederherstellen
- Skin-System (Dark Theme, erweiterbar)
- Crash-Recovery
- Mehrsprachigkeitsgrundlage (i18n)

## Version 2
- Lyrics-Fenster mit Auto-Scroll
- Notes und Aufgaben
- Pattern-Dauer-Warnung
- GEMA-Export
- Migration (Callers Caddy 1.0 + erste SquareView-Unterstützung)

## Spätere Versionen
- Statistikfunktionen
- Mehrere Layouts
- Weitere Hotkeys
- Bessere Metadaten-/Label-Erkennung
- Erweiterte Foto-Funktionen
