# Callers Caddy — Projektübersicht

## Vision
Spezialisiertes Arbeitswerkzeug für Square Dance Caller.
Abspielen, Anpassen und Organisieren von Square-Dance-Musik im Live-Betrieb.

## Positionierung
- Kostenlos, aber nicht Open Source
- Quellcode bleibt beim Entwickler
- Deutschsprachig als strategischer Vorteil, Englisch ebenso wichtig

## Zielgruppen
- Club Caller (regelmässig gleicher Club)
- Gastcaller (verschiedene Clubs)
- Special Caller (lange Veranstaltungen, GEMA)
- Neue Caller / Class Caller

## Prioritätsregel
Audio-Stabilität > Komfort > Plattformbreite
Windows zuerst, dann macOS, dann Mobile

## Plattformen
- Windows (primär, Laptop)
- macOS / iOS (sekundär)
- Android (tertiär)
- Tablets strategisch interessant

## Nicht-funktionale Kern-Anforderungen
- Offline-first, kein Internet nötig
- 10.000+ Songs performant
- Portabel (relative Pfade, Ordner kopierbar)
- Mehrsprachig (DE/EN) von Anfang an
- Lokale Datenhaltung, kein Cloud-Zwang
- Auto-Save überall (kein Speichern-Button)
